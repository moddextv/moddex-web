# Vendored skills

Design and animation skills vendored from
[emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT — see
`LICENSE`). They are checked in so the craft bar travels with the repo rather
than living on one machine.

Used to build the current design system: the motion tokens in
`src/styles/globals.css`, the bracket primitive derived from the logo, and the
review standards the components are held to.

Update by re-copying from upstream; do not edit in place.
