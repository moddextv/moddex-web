Routes with no ui

Eight of the app's routes never paint anything. They are listed here so the inventory beside them is honest — a page that is missing from the index should mean it does not exist, not that nobody drew it.

redirects

4
/c/[username] 308 → /channel/[username]
/u/[username] 308 → /user/[username]
/api/docs 308 → api.moddex.tv/docs
/docs 308 → api.moddex.tv/docs

The short urls are the design. moddex.tv/c/forsen and moddex.tv/u/forsen are the pair the home page prints, one per direction — they used to need a second domain, and on a .tv domain they no longer do. The copy button on every profile writes the short form, never the canonical one.

The docs left the building. They are generated from annotations that sit beside the routes they describe, and those routes moved to moddex-api. Both spellings redirect permanently: /api/docs is what was linked publicly, /docs is what people guess. The header's api item points at the internal path on purpose, so the redirect stays the single place that knows where the docs live.

route handlers

4
/health the docker healthcheck and status.moddex.tv both depend on it. do not remove or rename.
/api/auth/[...nextauth] twitch oauth. the only thing a reader sees of it is twitch's own consent screen, which is why there is no comp for signing in beyond the gate.
/api/checkout creates the stripe session that /donate hands off to. the webhook that records the payment lives on api.moddex.tv, not here.
/api/[...slug] catch-all. returns a json 404 rather than the html one, so a wrong api path never answers with a page.
