Suggestion v2

Built to sit inside the Twitch ecosystem

moddex is not a standalone product. It is a companion tool for one platform, used by people who arrive from that platform and go straight back to it. So it should look like it belongs there, and the way to do that is to copy the host's actual decisions rather than invent a mood.

Why the two earlier attempts failed

The first v2 was a dark terminal. The second was a paper almanac. Both read as generated, and it was the same mistake twice: they were costumes over the same wireframe. Heading, paragraph, table, section, table, in different clothes.

Worse, both reached for a house style that generators default to. A near-black canvas with two saturated accents is the first one. A light-weight serif on off-white paper is the second. The design-taste-frontend skill names the serif case explicitly and I broke that rule while quoting it approvingly. This direction fixes the cause rather than the symptom: it changes what the pages ARE, and it copies from a real interface instead of from a concept.

What was taken, and what it does

The nav search

Twitch keeps search in the top bar at all times. On moddex search IS the product, so it belongs there. This one move means no page needs a hero whose only job is to hold a search box, which is why the home page here looks nothing like the home page in the other two.

The left rail

Twitch's rail is followed channels. moddex's is recently looked up. Same job, and on a lookup tool it is arguably more useful than it is on Twitch.

Channel header and tabs

A moddex entry IS a channel page: avatar, name, follower count, a primary action, then tabs for the views of it. The two lookup directions are those tabs, because on Twitch a tab is a different view of the same subject.

The chatter list

Twitch's viewer list groups people by role under headings, each name carrying its badge, at chat-line rhythm. That is exactly what a moddex channel page is: a chatter list, persisted and dated. The single most useful borrow in the direction.

Chat badges

Twitch's own moderator badge is a green sword and its VIP badge is a pink gem, 18px, immediately before the username. moddex's mod green and vip pink were never an invention that happens to match Twitch, they ARE that convention.

The palette barely moved

moddex's dark ramp is already almost exactly Twitch's. It was never the reason the site felt generic.

Every page

Worth arguing about

  • Inter, which is what Twitch ships. The skill discourages it as a default and names the override; a brief of "look like the host" is that override.
  • 4px radius, which the shipped design bans on the grounds that the mark has no curves. A logo does not have to dictate a button.
  • Looking like Twitch means looking less distinctive. That is the trade, and for a companion tool it is usually the right one.
  • Copy carries no em-dashes, which is a voice change as well as a visual one.
  • The dashboard below the heading is a proposal. The shipped page is a stub.

What shipping it needs

  • Inter self-hosted, the same way Lato and Cairo already are in src/app/fonts.
  • One palette value changed in tailwind.config.mjs.
  • Radius unbanned in globals.css.
  • A rail component, which is genuinely new. Everything else maps onto components that already exist.
