Suggestion v1

The same site, with its own rules enforced.

v1 is the evolution. Same brand, same routes, same dark canvas, same two hues. Nothing here asks you to relearn the product.

What changed is that the design system the shipped site describes in its own comments is now actually applied everywhere, and the four things it was missing are in place. If you want a different visual language rather than a better version of this one, that is v2.

The four changes that carry it

A body typeface

Lato is self-hosted in src/app/fonts and loaded by layout.tsx, but no element carries font-lato, so every paragraph on the live site renders in the browser default sans. This is the single largest visual change in v1 and it costs one class.

One measure

/donate, /donate/success, /settings, /tos and /dashboard wrap in max-w-3xl px-6 while everything else uses the 5xl Container, so those five pages sit on a different left edge than the wordmark above them. One container, everywhere.

Data set as data

Role lists become tables with column heads, so the two numbers on the right of every row stop being a mystery until hovered. One rule under the head instead of a hairline under all 24 rows.

A colour lock

Mod green and vip pink appear only on role data. Never a button, a link, a border or a focus ring. The shipped site follows this loosely; making it absolute is what lets the two hues mean something when they do appear.

Every page

Kept, deliberately

  • The mark, unchanged, including the two-corner bracket vocabulary.
  • Every colour value in the palette.
  • Every route, slug, anchor id and nav label.
  • Cairo for display and the square-cornered geometry.
  • The dark canvas. There is no light mode to honour and no toggle.

Worth arguing about

  • Copy is rewritten to carry no em-dashes, which the taste skill bans outright. That is a voice change, not just a visual one, so it is your call whether it comes back with the rest.
  • The dashboard below its first line is a proposal, not a redraw. The shipped page is a stub.
  • The 403 for an opted-out account no longer reads as an error. It is the privacy promise working.
