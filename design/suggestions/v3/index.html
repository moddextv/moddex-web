Suggestion v3

Built from five verdicts, not a concept

Four earlier attempts each got rejected for a different reason. This one is not another idea; it is those five reasons applied in order.

What each attempt taught

AttemptVerdictWhat it settled
v1 Index liked Dark, modern sans, room to breathe.
v2 Telemetry read as generated Dark canvas plus saturated accents plus tracked-out mono is a house style.
v2 Almanac read as generated Light serif on paper is the other house style. Both were costumes over one wireframe.
v2 Native kind of, not quite Structure was right. Identity was Twitch's, not moddex's.
v3 Records old-fashioned, table-like, clamped No Arial, no bordered grids, no squeeze.

Kept

The three things v2 got structurally right.

  • Search in the nav, so no page needs a hero whose only job is to hold a search box.
  • A profile header with tabs for the two lookup directions.
  • Roles as lists of people, never as a spreadsheet.

Its own identity

The fix for "not quite".

  • Purple is demoted to the two controls that actually talk to Twitch. Everywhere else the accent is the mark's own green and pink.
  • The left rail is gone. It was the most obviously borrowed element and it was eating 240px of width.
  • The tab underline is the role's colour, so which direction you are reading is stated in the brand's own notation.

Opened up

The fix for "clamped", in numbers.

row height 26px to 52px
base type 13px to 15px
container 1200 to 1440
gutters 12px to 32px
panel padding 8px to 24px

Every page

Still worth arguing about

  • Manrope is one line in assets/theme.js. Cheap to swap, and cheapest before 19 pages exist.
  • Copy carries no em-dashes, which is a voice change as well as a visual one.
  • The dashboard below its heading is a proposal. The shipped page is a stub.
  • The 403 for an opted-out account no longer reads as an error, because it is the privacy promise working.

What shipping it needs

  • Manrope self-hosted, the way Lato and Cairo already are in src/app/fonts. next/font/local is already wired.
  • Radius unbanned in globals.css, which currently forces 0 on every control.
  • No palette change at all. Every colour is the shipped dark theme.
  • The four fixes from the audit, which apply whichever direction wins.
